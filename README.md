# Blog API (Laravel 13 + Vue + Inertia + TypeScript)

A personal **API blog portfolio** built with the modern **VILT stack** (Vue, Inertia, Laravel, Tailwind), designed to showcase professional development practices.  
This project is cloud‑native, API‑first, and follows industry standards for deployment, testing, and documentation.

---

## 🚀 Features
- Laravel 13 with Octane + FrankenPHP for high performance
- REST API (`/api/v1/...`) with versioning
- Vue 3 + Inertia + TypeScript frontend
- Tailwind CSS for styling
- PostgreSQL database with Redis caching
- Authentication with Laravel Breeze + Sanctum
- Pest testing framework
- API documentation via Scramble
- Docker + Sail for local development
- GitHub workflow for version control

---

## 🛠️ Requirements
- Docker & Docker Compose installed
- Git installed
- Node.js & npm (for frontend assets)
